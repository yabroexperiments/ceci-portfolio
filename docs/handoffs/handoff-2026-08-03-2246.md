## 8. Gotchas & Landmines (each cost real time this session)
- **Bare lh3 URL = 512px DEFAULT; =s0 = true original.** Re-downloading images "as
  referenced" reintroduces blur. Never "re-sync" `site/assets/img/` from source URLs.
- **`data-ecommerce-solution="DISABLED"` must stay on every page** — removing the
  attribute makes the JS read undefined, which FAILS the =="DISABLED" guard and
  re-enables the phone-home. It's the off-switch, not a mention.
- **`rip_live.py` (now `legacy/`) must never run against `site/`** — output
  re-introduces every IM Creator dependency.
- The IM Creator engine's `=s300→=s(2×width)` runtime resize was the responsive-image
  system, not dead glue; patches to vendored JS need a "what did this DO" analysis.
- Verification gates that check requests/naturalWidth pass 4×-undersized images —
  sharpness needs intrinsic-vs-displayed dimension checks (both blur bugs shipped
  through "zero broken images" gates).
- The independent audit's "no forms anywhere" was wrong (172 empty `preview-form`
  stubs exist; the submit path was dead for a different reason — zero SUBMIT links).
  Verify subagent claims that gate real decisions.
- Hidden browser pane throttles background-tab timers (detached JS loops stall);
  same-origin stale cache mimics 404/regression after content swaps → fresh port.
- GitHub Pages deploys `site/` on every push to `main` (~30s). Branches don't deploy.
