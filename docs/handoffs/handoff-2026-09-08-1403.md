## 8. Gotchas & Landmines
- **Deploys are cache-invisible.** GitHub Pages sends `cache-control: max-age=600`.
  A bug report made inside 10 minutes of a deploy may be about the OLD build —
  this exact confusion cost a round trip today. Always ship the hard-refresh
  instruction with any "it's live" message.
- **Structural checks cannot see a visibility bug.** `opacity: 0` passes
  "element present", "image decodes", "link resolves". Screenshots found two
  bugs that every structural pass missed.
- **The hidden browser pane** never fires `rAF` or IntersectionObserver, does not
  run CSS animations or transitions, and does not repaint after a programmatic
  scroll. To see lower content, shift `document.body.style.marginTop` (a layout
  change forces a repaint) — scrolling does not work.
- **The preview server cannot read `~/Documents`** (macOS TCC): it starts and
  404s everything. Serve from the session scratchpad.
- **`computer` screenshots capture the FRONTED tab**, ignoring `tabId`. Close or
  front the right tab first — two screenshots were silently of the wrong page.
- **Her export is reformatted** between drops; any new patch must be
  attribute-order-agnostic or it becomes a silent no-op.
