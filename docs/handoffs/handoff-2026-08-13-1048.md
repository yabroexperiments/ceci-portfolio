## 8. Gotchas & Landmines
- **A `str.replace()` patch whose target disappears is a SILENT no-op.** Bit us exactly:
  Ceci removed the About pill, so that remap quietly did nothing while looking healthy.
  Now every patch counts its matches and errors at zero. (Also in `~/.claude/CLAUDE.md`
  and FACTS §28.)
- **A copy-only sync accumulates.** 5 renamed/dropped images stayed live under "all checks
  passed". `site/images` is now mirrored (copy + prune + log).
- **The Bash tool's cwd persists across calls — it bit me again.** A compound command
  ending inside `site/images` made the *next* call's relative `rm site/images/...` fail.
  Open every call with `cd <abs> &&`. The rule was already written down; writing it down
  is evidently not enough.
- **Hidden browser pane throttles: screenshots after a programmatic scroll came back blank
  white.** Don't debug it — verify static sites with one `javascript_exec` that `fetch()`es
  every page, `DOMParser`s it, and HEAD-checks each asset. Full coverage, one call.
  Screenshots only for what pixels alone answer, taken at the top of a page.
- **AC's browser cache made a verified-correct deploy look unshipped** ("landing page is
  still old"). Second occurrence. Always attach `Cmd+Shift+R` to the success message.
- **Gate deploys on YOUR SHA's run id**, never `gh run list --limit 1` (carried over from
  the previous brief; followed correctly three times this session).
- `preview_start` cannot launch `python3 -m http.server` (macOS sandbox denies
  `os.getcwd()`), so the server is started with `Bash` + `nohup` and `launch.json` just
  attaches to `http://localhost:8899`.
